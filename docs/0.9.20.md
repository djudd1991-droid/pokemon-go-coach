# GO Coach 0.9.20

The home screen has one clear start action, consistent dark surfaces and a
compass icon. The compact floating coach retains two lines of status; expanding
reveals pause, stop, details, optional map correction, record review and save.

  merging in Wild Map. Require the map menu to separate night maps from catch screens.
- Require a cyan head and narrow stem for PokéStops, not color alone.
- Keep explicit buddy/profile exclusion and Unknown labels for unidentified candidates.
- Suppress night ground only in map appearance descriptors.
- Cache normalized names, reuse clear header OCR and mask the coach before OCR.
- Confirm names without CP. CP changes do not restart learning or count another visit.
- Save the confirmed name before automatic map teaching.

  no longer silently deletes duplicate records.
- Format all Java, extract home/style and map view/model helpers, remove unused
  legacy map scanning, and track readable source with generated ZIPs.

## Desktop validation

Eight logic suites pass: scanner/tracker, learning/persistence, collection auto-save,
memory/migration/moves, name/power-up recognition, grades, advice and screen routing.
New checks cover missing CP, cached exact names, night appearance, a cyan stop
with a stem and a cyan body without one.

Three supplied phone screenshots passed explicit local checks: four Unknown
candidates on the crowded night map, one on the earlier map, catch-screen rejection.
These screenshots remain local. Thirty warmed detector runs per map gave medians
of 1.44 ms and 1.05 ms on the PC (p95 3.90 ms and 1.54 ms). This is detector-only
timing, not Android capture/OCR/end-to-end latency.

## Phone acceptance test

1. Install over the existing test app; check saved collection and learning counts.
   Do not uninstall to update.
2. Start, approve sharing and open Pokémon GO. Check compact status, expand/collapse,
   drag, pause/resume and stop.
3. Test day and night maps. After two stable frames, verify markers follow spawns,
   ignore buddy/profile portraits and disappear when spawns disappear.
4. Open a spawn. Map markers should clear. Keep its name visible, with CP hidden if
   desired, and check Learning memory after two readings.
5. With one preceding map candidate, check tentative appearance recognition after
   returning to the map. Crowded maps may need optional correction.
6. Delete species/all map examples; verify encounter history, pictures and collection
   remain. Show details/appraisal and verify moves and grades still save.

Detection is heuristic: unusual zoom, weather, pale/dark bodies, overlaps and
different layouts can be missed. One detected candidate does not guarantee no
other spawn was missed. Crowded-map automatic identity, complete 3D recognition,
account linking and the planned coaching features remain unfinished.
